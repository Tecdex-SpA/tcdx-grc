# I04 — Matrices y presentación preparada

matrix-source.ts deriva seis SELECT parametrizados de relaciones canónicas. matrix-service.ts reautoriza, usa lector compartido READ ONLY/REPEATABLE READ y controles canónicos de objetos/packs. matrices.ts valida filtros tipados, límites publicados, permisos de todas las fuentes, eje/celda, fingerprint del conjunto visible y cursores separados ligados a ventanas/actor/tenant/permisos. SQL se analizó offline con gramática PG16; no se ejecutó.

normative-library.tsx prepara lector API, tabla común de miniatura/vista completa, inspector de procedencia/estado, contexto de error/no acceso/vacío y contenido Knowledge con COMPRENDER/IMPLEMENTAR/DEMOSTRAR. Misma fuente para ambas presentaciones, sin scores, porcentajes o semáforos de cumplimiento inventados. Los rótulos de interacción son españoles y se reutilizan clases/tokens existentes; se mantienen datos/estados originales para trazabilidad.

B09 usa únicamente state efímero React, sin localStorage, presets persistidos, exportación ni Report Studio. No se añade navegación Riesgos ni se inicia su módulo. Componentes NO montados en main/core-grc y no disponibles en QA. Harness exclusivamente de test sintético, nunca importado por main.

Pruebas visuales locales desktop/narrow PASS (dos casos), teclado/inspector, no overflow global y cero solicitudes fuera de localhost. Capturas evidence/library-*.png.
