# Enmienda visual - entrega integral QA 2026-10-22

Autoridad: instrucción expresa del Product Owner, ejecución
`QA_FULL_FUNCTIONAL_CLOSURE_NORMATIVE_CONTRACTING_PREMIUM_UI`.
Baseline rectora: `TCDX_GRC_MASTER_REGENT_BASELINE_v1.12_2026-10-16`.

La instrucción autoriza modernizar integralmente la presentación del frontend
existente. Amplía la dirección de v1.0 a todas las superficies implementadas:
shell, dashboard, biblioteca y catálogo, tablas, matrices, formularios, detalles,
administración e identidad. Es autorización de diseño e implementación; no
representa aceptación humana de capturas o bytes futuros.

Se conservan logo local aprobado, naranja #F0721D, teal #51ABA8, navegación navy,
contenido en español, permisos, rutas y semántica canónica. La geometría puede
evolucionar para cumplir la modernización integral aprobada: encabezados compactos,
jerarquía tipográfica consistente, superficies con bordes discretos, densidad útil,
acciones proporcionadas y estados vacíos breves. Se consolida el CSS compartido;
no se introduce otra biblioteca de componentes ni una dependencia tipográfica externa.

Escala: texto 13-16px, títulos de página 24-28px, secciones 15-18px, valores de
indicadores 28-34px; espaciado 4/8/12/16/24/32px; radios 8/15px. Acciones primarias
naranja con texto navy contrastado, secundarias neutras y foco visible teal.
Tablas conservan encabezados y relaciones; matrices conservan ambos ejes y
detalle de correspondencias. Los datos, ausencias y restricciones son reales.

Las imágenes v1.0 siguen como antecedentes humanos aprobados y no se sobrescriben.
Las capturas de la entrega son evidencia de implementación, no nuevas imágenes
humanamente aceptadas. Se requieren navegador compilado/desplegado, desktop,
tablet y mobile, teclado/foco/etiquetas, ausencia de overflow principal y regresión.
`HUMAN_UI_REVIEW=PENDING` hasta revisión explícita del PO sobre QA.

Esta enmienda prevalece únicamente sobre la prohibición de rediseño sustancial
de v1.0 y su geometría anterior. Conserva los restantes seis contratos visuales,
la autoridad superior, H04 y SoD. No modifica la baseline rectora inmutable.

Referencia visual adicional indicada por el PO: https://tcdx-iso.tecdex.net/.
Se inspeccionaron dashboard y registro de riesgos autenticados. Se toma como
referencia de composición, jerarquía y acabado, sin adoptar sus contratos, métricas,
datos, logo alternativo ni estados funcionales. No se almacenan credenciales.
