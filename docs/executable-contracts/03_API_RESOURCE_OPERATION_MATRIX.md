## Normative conventions

Paths are relative to `/api/v1`. A `:command` suffix is an explicit domain command, never generic `update_status`. `tenant` means the selected `X-TCDX-Tenant-Id` has been authenticated against active membership, entitlement, permission, scope, object policy and SoD. `platform` means no tenant is fabricated. All IDs are opaque UUIDv7.

Abbreviations: `NAT=NATURALLY_IDEMPOTENT`, `KEY=IDEMPOTENCY_KEY_REQUIRED`, `RECON=NON_RETRYABLE_WITHOUT_RECONCILIATION`; `TX` means aggregate mutation + required audit/outbox in one PostgreSQL transaction; `RO` read-only. Error set `COMMON` is defined in 06. Requests/responses use the resource schema named in the row plus the common envelopes in 02; command requests contain only command inputs, `reason` when required and `expected_version` for mutable critical resources.
