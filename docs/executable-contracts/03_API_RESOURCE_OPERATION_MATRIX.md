## Normative conventions

Paths are relative to `/api/v1`. A `:command` suffix is an explicit domain command, never generic `update_status`. `tenant` means the selected `X-TCDX-Tenant-Id` has been authenticated against active membership, entitlement, permission, scope, object policy and SoD. `platform` means no tenant is fabricated. All IDs are opaque UUIDv7.

Abbreviations: `NAT=NATURALLY_IDEMPOTENT`, `KEY=IDEMPOTENCY_KEY_REQUIRED`, `RECON=NON_RETRYABLE_WITHOUT_RECONCILIATION`; `TX` means aggregate mutation + required audit/outbox in one PostgreSQL transaction; `RO` read-only. Error set `COMMON` is defined in 06. Requests/responses use the exact closed schema named in the row plus the common envelopes in 02; command requests contain only authoritative command inputs, `reason` when required and `expected_version` for mutable critical resources.

The ten Phase 5 collection GETs use cursor pagination only: `page[size]` integer 1..100, default 25; invalid values return COMMON HTTP 400. Stable order is `created_at DESC, <entity_primary_id> DESC`. The opaque cursor encodes both order components plus server-controlled continuation/filter context, never grants tenant/scope authority and cannot select offset pagination.
