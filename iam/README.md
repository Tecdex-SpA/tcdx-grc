# TCDX GRC end-user IAM login theme

This source owns only the login presentation for the `tcdx-managed-identity` realm. It inherits the `keycloak.v2` login theme from the exact Keycloak 26.7.5 base image pinned in `Dockerfile`. Keycloak continues to render and receive username, password, TOTP, required actions, errors, information and logout forms. The Admin Console and realm security settings are outside this image change.

The local Tecdex logo is the approved versioned asset from `docs/ui/assets/brand/tecdex-logo-light.svg`. Colors, radius, type and focus treatment follow the active `docs/ui` v1.0 contracts and existing frontend tokens. No network brand asset is loaded by the theme.

Theme tests run with `node --test iam/theme.test.mjs`. After building the local image, `node iam/run-theme-e2e.mjs` starts and removes a disposable Keycloak container bound to `127.0.0.1:4898`. The realm/client/user fixtures are synthetic; credentials are generated for each run, never written to source or reports, and the protected temporary import is removed after import. Browser traces/video are disabled. TOTP setup screenshots mask the QR code. This validates theme presentation and forms; its fixture realm is not the approved production browser-flow/security configuration and does not prove a GRC runtime MFA gate.

Build locally with `docker build -f iam/Dockerfile -t tcdx-grc-iam-theme:mi7-local iam`. Selecting `tcdx-grc` as the realm login theme and replacing the IAM runtime require a separate authorized runtime step. This repository change does not update the running realm or public Admin Console.

Keycloak 26.7.5's `keycloak.v2` theme supplies login, password update, TOTP configuration and OTP challenge templates; its `base` parent supplies error, information and logout confirmation templates. The exact upstream sources are under `themes/src/main/resources/theme/` at tag `26.7.5` in the Keycloak repository. Image inspection during MI7 checked that these templates exist in `org.keycloak.keycloak-themes-26.7.5.jar`. `upstream-templates.json` records source URLs and hashes for the three versioned overrides: the common layout changes the favicon and corrects the readonly username label; TOTP setup fixes upstream label associations, error descriptions and localized QR alternative text; the field macro associates input errors with their controls. Form actions, credential handling and session scripts retain their upstream logic, verified by the theme tests.
